

Atividade: Desvendando a Nuvem com AWS

O que é a AWS A Amazon Web Services (AWS) é uma plataforma de serviços de computação em nuvem que oferece infraestrutura de TI sob demanda. Isso permite que empresas utilizem servidores, armazenamento e bancos de dados através da internet, eliminando a necessidade de investir e manter equipamentos físicos locais.

Infraestrutura Global A estrutura da AWS é projetada para oferecer alta disponibilidade e resiliência, dividindo-se em:

Regiões: São áreas geográficas globais que agrupam centros de dados. Elas são isoladas entre si para garantir que falhas em uma região não afetem as demais.

Zonas de Disponibilidade: Localizadas dentro das regiões, são centros de dados independentes com sistemas de energia e rede próprios. Se uma zona falhar, as outras garantem que o serviço continue ativo.

Economia da Nuvem

Modelo de Precificação (Pay-as-you-go) O modelo funciona no sistema de pagamento por uso. Não há custos iniciais elevados; o usuário paga apenas pela quantidade de recursos consumidos e pelo tempo de utilização. Isso transforma custos fixos de hardware em custos variáveis de acordo com a demanda.

Economia de Escala A AWS gera lucro através da escala massiva de sua operação. Por atender milhões de clientes, a empresa compra hardware e infraestrutura em grandes volumes por preços reduzidos. Essa eficiência operacional permite reduzir os custos unitários e repassar economias para os clientes na forma de preços menores.
